# SM Knowledge Bot 操作指南（模拟知识文件）

此文件会在 Java 服务启动时自动写入 SQLite 并建立知识索引，供问答功能直接检索。

## 安装全部 Skill（推荐）

```powershell
npx skills add https://github.com/Unclecheng-li/AI_Animation
```

## 安装单个 Skill

```powershell
npx skills add https://github.com/Unclecheng-li/AI_Animation/tree/main/skills/ppt-animation
npx skills add https://github.com/Unclecheng-li/AI_Animation/tree/main/skills/flowchart
npx skills add https://github.com/Unclecheng-li/AI_Animation/tree/main/skills/network-protocol-viz
npx skills add https://github.com/Unclecheng-li/AI_Animation/tree/main/skills/dynamic-archify
npx skills add https://github.com/Unclecheng-li/AI_Animation/tree/main/skills/scholar-notes
```

## 项目安装

```powershell
git clone https://github.com/StavinLi/Workflow.git
cd .\Workflow
```

克隆完成后，阅读项目中的 `README.md` 并执行其依赖安装和启动说明。

## 导入 GitHub 仓库到知识库

```powershell
Invoke-RestMethod http://127.0.0.1:8080/documents/import/github `
  -Method Post `
  -Headers @{ 'X-User-Id' = 'admin' } `
  -ContentType 'application/json' `
  -Body '{"repository_url":"https://github.com/Unclecheng-li/AI_Animation","department":"engineering"}'
```

## 知识库问答

```powershell
Invoke-RestMethod http://127.0.0.1:8080/chat `
  -Method Post `
  -Headers @{ 'X-User-Id' = 'admin' } `
  -ContentType 'application/json' `
  -Body '{"question":"如何安装全部 Skill？"}'
```

返回的 `conversation_id` 用于后续问题，形成多轮对话。
