# SM Knowledge Bot 操作指南（模拟知识文件）

此文件会在 Java 服务首次启动时自动写入 SQLite 并建立知识索引，供问答功能直接检索。

## 1. 启动 Java 服务

```powershell
cd C:\Users\Admin\Desktop\github项目\SM-knowledge-bot\java
.\start-java.ps1
```

访问 `http://127.0.0.1:8080/health`，返回 `status: ok` 即成功。

## 2. 同步 GitHub 仓库

使用管理员 `admin` 调用：

```powershell
Invoke-RestMethod http://127.0.0.1:8080/documents/import/github `
  -Method Post `
  -Headers @{ 'X-User-Id' = 'admin' } `
  -ContentType 'application/json' `
  -Body '{"repository_url":"https://github.com/luoshitianchen/SM-knowledge-bot","department":"engineering"}'
```

## 3. 发起问答

```powershell
Invoke-RestMethod http://127.0.0.1:8080/chat `
  -Method Post `
  -Headers @{ 'X-User-Id' = 'admin' } `
  -ContentType 'application/json' `
  -Body '{"question":"如何同步 GitHub 仓库？"}'
```

返回的 `conversation_id` 用于下一次问题，形成多轮对话。

## 4. 权限

- `employee`：问答；
- `manager`：问答、录入文档、同步 GitHub；
- `admin`：全部权限及用户创建。
