# 知识问答机器人服务 灾难恢复手册（DR_RUNBOOK）

> 服务：`sm-knowledge-bot` ｜ 端口 8023 ｜ 数据库 `sm_knowledge_bot`

## 1. 数据库备份恢复步骤
1. 确认备份存在：`backupctl list --service sm-knowledge-bot`。
2. 在隔离库恢复最近全量备份：`backupctl restore --full <backup-id> --to <临时库>`。
3. 重放 WAL 至故障点（PITR），执行完整性校验。
4. 将恢复库地址切至服务配置并验证。

## 2. 服务降级方案
- 非核心接口（如统计、报表）可临时关闭，优先保障读写主链路。
- 数据库不可用时，返回降级提示页，写入队列暂存待恢复后回放。
- 降级开关通过配置热更新或 Feature Flag 控制。

## 3. 跨可用区/跨区域切换
1. 确认目标可用区/区域有同版本副本与数据副本。
2. 更新 Ingress/DNS 指向目标区域，ArgoCD 切换目标集群 Application。
3. 按"健康检查 → 核心接口冒烟 → 业务验证"顺序放量。
4. 原区域恢复后作为新备，避免双活写入冲突。

## 4. 演练频率与记录
- 每月一次恢复校验，每季度一次完整容灾演练。
- 每次演练记录：时间、执行人、RTO/RPO、问题项与闭环情况，归档至运维工单系统。
